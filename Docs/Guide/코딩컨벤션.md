# 코딩 컨벤션

> 사람과 Claude 가 보는 문서. 로컬 LLM 용 짧은 요약본은 `코딩컨벤션-요약.md`.
> **기계가 잡아주는 건 여기 안 쓴다.** 서식은 CSharpier, 함정은 애널라이저가 잡는다.
> 마지막 고침 : 2026-08-21

## 0. 지금 상태

사용자가 **SOLID + 아래 8가지**만 먼저 정했다. 나머지는 필요해질 때 더한다.

## 1. SOLID

층에 따라 다르게 본다. (근거 : 스튜디오 저장소의 스튜디오키트 결정사항 문서, 2026-08-20)

- **순수 C#** (전투·인벤토리·상태·데이터) : 전부 적용한다.
- **MonoBehaviour** : 컴포넌트 조합이 기본이다. 억지로 인터페이스를 끼우지 않는다.

## 2. 규칙

### 2-1. partial 은 되도록 쓰지 않는다

한 클래스가 여러 파일에 흩어지면 전체를 보기 어렵다.
자동 생성 코드처럼 어쩔 수 없는 경우만 쓴다.

### 2-2. 내부 클래스(중첩 클래스)는 금지

```csharp
// 나쁜 예
public class Inventory
{
    private class Slot { public int Id; }
}

// 좋은 예 — 파일을 나눈다
public class Inventory { }
public class InventorySlot { public int Id; }
```

### 2-3. 3년차 프로그래머가 바로 읽히는 코드로 쓴다

똑똑한 한 줄보다 평범한 세 줄이 낫다. 아무도 기계로 못 잡는 규칙이라 리뷰에서 본다.

### 2-4. 들여쓰기 깊이는 3단계까지를 권장한다

강제는 아니다. **3단계를 넘으면 함수로 뺄 때가 됐다는 신호**로 읽는다.
대부분은 조건을 뒤집어 일찍 빠져나오면 풀린다.

```csharp
// 나쁜 예 — 4단계
if (a != null)
{
    if (a.IsAlive)
    {
        foreach (var x in a.Items)
        {
            if (x.Count > 0) { Use(x); }
        }
    }
}

// 좋은 예 — 일찍 빠져나온다
if (a == null) { return; }
if (!a.IsAlive) { return; }

foreach (var x in a.Items)
{
    if (x.Count <= 0) { continue; }
    Use(x);
}
```

### 2-5. `? :` 와 `??` 는 되도록 쓰지 않는다

읽는 사람이 한 번 멈춘다. `if` 로 풀어 쓴다.
`?.` 도 같은 이유로 조심한다.

### 2-6. 주석에 히스토리를 쓰지 않는다

- 언제 누가 왜 고쳤는지는 **git 이 기억한다.** 주석·JSON `description`·`memo` 어디에도 쓰지 않는다.
- **최대 2줄.** 어쩔 수 없으면 3줄까지.
- 이유를 길게 늘어놓지 말고 **요약**한다.
- 코드를 보면 바로 아는 내용은 아예 쓰지 않는다.

```csharp
// 나쁜 예
// 2026-08-19 김OO 추가. 처음엔 리스트였는데 성능 문제로 딕셔너리로 바꿈.
// 자세한 건 이슈 #123 참고.

// 좋은 예
// 아이디로 자주 찾아서 딕셔너리로 둔다.
```

### 2-7. `if` 안이 2줄 이상이면 중괄호를 반드시 쓴다

```csharp
// 괜찮다
if (dead) { return; }

// 반드시 중괄호
if (dead)
{
    Cleanup();
    return;
}
```

### 2-8. 2중첩부터는 한 줄이어도 중괄호를 반드시 쓴다

```csharp
// 나쁜 예
foreach (var x in items)
    if (x.Ok)
        Use(x);

// 좋은 예
foreach (var x in items)
{
    if (x.Ok) { Use(x); }
}
```

### 2-9. 두 번 이상 반복되는 코드가 아니면 함수로 빼지 않는다

한 번만 쓰는 코드를 함수로 빼면 읽는 사람이 정의를 찾아 왔다 갔다 하게 된다.
그냥 그 자리에 둔다.

**2-4(깊이 3단계)와 부딪히면 2-9 가 이긴다.**
깊이가 깊다고 함수로 빼지 말고, **일찍 빠져나오기(early return)로 푼다.**
