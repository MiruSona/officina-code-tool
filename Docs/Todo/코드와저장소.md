> 담당 범위 : 대상 프로젝트에 넣어줄 코드 템플릿 · 컨벤션 · 저장소 MCP

## 1. 정해진 것

### 코드 구조

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 기본 구조 | **4층** — Master / Manager·Hub / Object / Agent·Util | `Todo/기본구조.md` |
| 앱 전체를 사는 층 | 위 4층 **위에 3층 추가** — `GameMaster`(static) / `GameRunner`(Mono) / `~Service`(순수 C#) | `Design/2026-08-20-기본구조설계.md` |
| Update 진입점 | **`GameRunner` 하나뿐.** `~Master` 는 Mono 지만 `Update` 를 안 쓴다 | 〃 |
| Mono 인 것 | `GameRunner` · `~Master` · `~Object` **셋뿐.** 나머지는 순수 C# | 〃 |
| 꺼내 쓰는 길 | 전역이든 씬이든 **`~Hub` 하나로 통일** | 〃 |
| 등록·해제 | 등록은 남이, **해제는 `OnDestroy` 에서 자기가** | 〃 |
| ECS/DOTS | **안 쓴다 (보류).** SpriteRenderer 가 컴패니언 컴포넌트라 2D 에서 이득이 적다 | `Research/2026-08-20-ECSDOTS구조조사.md` |
| 인스펙터 배선 | **금지.** AI 는 인스펙터를 못 본다 | 스튜디오 저장소 공용 규칙 10번 |
| Unity | **Unity 6 LTS + 2D URP 확정** (게임마다 바꿀 수 있어야 함) | 스튜디오 저장소의 스튜디오키트 결정사항 (2026-08-20) |
| asmdef | 처음엔 **Runtime / Editor 2개만.** 기능별로 쪼개면 손해 | 〃 |
| 코드 폴더 | **기능별.** 그림·소리는 유형별 | 〃 |
| 네임스페이스 | 기본값 `Officina.*`, **설정으로 바꿀 수 있어야 한다** | 〃 |
| SOLID | **층을 나눠 본다.** 순수 C#(전투·인벤토리·상태·데이터) = 전부 적용 / MonoBehaviour = 컴포넌트 조합이 기본 | 〃 |
| Unity 조작 도구 | **지금은 안 깐다.** 배치모드 → 공식 CLI → uloop-cli → (마지막) MCP | 〃 |
| Init 순서 | **Master 의 등록 순서 그대로.** `Init`(자기 것만) / `PostInit`(Hub.Get 은 여기서만) 2단계 | `Design/2026-09-01-2차설계.md` |
| Agent vs Util | 상태 있고 owner 받으면 `~Agent`, 무상태면 `~Util`(**`static class`**). 옛 이름 Handler 를 Util 로 바꿈 | 〃 |
| `Hub.Get` 실패 | **예외를 던진다**(`HubNotFoundException`). 없을 수 있는 곳만 `TryGet`, 중복 등록도 예외 | 〃 |
| Process 중 목록 변경 | **버퍼 둘 + 즉시 dead 표시.** `ProcessList<T>` 하나만 쓴다 (추가는 다음 프레임, 제거는 순회 끝) | 〃 |
| 두 Hub 걸치기 | **금지.** 소유 Master 의 Hub 하나만 등록, 남의 것은 꺼내 쓴다. 양쪽에 늘 필요하면 Service | 〃 |
| Object 생성 | `Instantiate` 는 **ResourceService 한 곳뿐**, **전원 풀링**(`Rent`/`Return`), 키는 코드 상수 `PrefabKeys` | 〃 |
| Manager 끼리 알림 | **중앙 EventBus** — 타입 기반 · 동기 즉시 호출, 이벤트는 `readonly struct`. Hub 는 pull 전용 | 〃 |

### 컨벤션

| 항목 | 결정 |
| --- | --- |
| 문서 개수 | **둘로 쪼갠다.** `코딩컨벤션.md`(사람·Claude용) + `코딩컨벤션-요약.md`(로컬 LLM 용, **100줄 이내**) |
| 핵심 경계 | **기계가 잡는 건 문서에 안 쓴다.** 규칙 개수만 늘어나 정작 중요한 게 묻힌다 |
| 자동 고침 | CSharpier (서식) |
| 설정 파일 | **`.globalconfig`** — Unity 가 `.editorconfig` 를 무시한다 (Won't Fix) |
| 애널라이저 | Microsoft.Unity.Analyzers (Unity 함정 43종), BannedApiAnalyzers (금지 API) |
| 문서에 쓸 것 | **이름을 무엇으로 지을지** — 아무도 못 잡는 것만 |
| 규칙 형태 | 규칙 한 줄 + 좋은 예 / 나쁜 예 한 쌍 |
| 기성 컨벤션 스킬·MCP | **안 쓴다.** 쓸 만한 게 없다 |
| 컨벤션 내용 | **1차 받음** — SOLID + 8가지. `Guide/코딩컨벤션.md` 에 정리됨. 나중에 더 준다 |

### 저장소 MCP

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| AI 기억 저장소 | **아무것도 안 붙인다** | `Docs/` + git + `CLAUDE.md` + 오토 메모리로 충분 |
| 코드베이스 저장소 | **지금은 할 일 없음** | Unity 프로젝트가 없어 색인할 코드가 없다 |
| 둘을 합치기 | **안 된다** | 성격이 정반대. 코드 색인은 버려도 되지만 기억은 날리면 끝 |
