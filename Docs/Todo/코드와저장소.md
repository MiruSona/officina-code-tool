### 컨벤션

| 항목 | 결정 |
| --- | --- |
| 문서 개수 | **둘로 쪼갠다.** `코딩컨벤션.md`(사람·Claude용) + `코딩컨벤션-요약.md`(로컬 LLM 용, **100줄 이내**) |
| 핵심 경계 | **기계가 잡는 건 문서에 안 쓴다.** 규칙 개수만 늘어나 정작 중요한 게 묻힌다 |
| 자동 고침 | CSharpier (서식) |
| 설정 파일 | **`.globalconfig`** — Unity 가 `.editorconfig` 를 무시한다 (Won't Fix) |
| 애널라이저 | Microsoft.Unity.Analyzers (Unity 함정 43종), BannedApiAnalyzers (금지 API) |
| 문서에 쓸 것 | **이름을 무엇으로 지을지** — 아무도 못 잡는 것만 |
| 규칙 형태 | 규칙 한 줄 + 좋은 예 / 나쁜 예 한 쌍 |
| 기성 컨벤션 스킬·MCP | **안 쓴다.** 쓸 만한 게 없다 |
| 컨벤션 내용 | **1차 받음** — SOLID + 8가지. `Guide/코딩컨벤션.md` 에 정리됨. 나중에 더 준다 |

### 저장소 MCP

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| AI 기억 저장소 | **아무것도 안 붙인다** | `Docs/` + git + `CLAUDE.md` + 오토 메모리로 충분 |
