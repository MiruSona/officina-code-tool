## 막힌 것

- **PowerShell 에서 `eval` 에 C# 코드를 인수로 넘기면 깨진다.** `+` · 따옴표가 셸에서 갈라져
  「--timeout 에 Int32 필요」 같은 엉뚱한 오류가 난다. 코드를 파일로 쓰고 `eval_file --file <경로>` 로 넘기면 된다.
- **`capture_game_view` 는 성공해도 종료 코드 255 를 낸다.** 종료 코드로 성공을 판정하면 틀린다. 저장된 파일이 있나로 본다.
- **`capture_game_view save_path` 가 프로젝트 폴더 밖이면 400 으로 거절한다.** 프로젝트 안에 찍고 옮겨야 한다.
- **Play 중 Editor 가 죽으면 다음 실행 때 「Recovering Scene Backups」 창이 뜨고 CLI 가 막힌다.** 사람이 창을 눌러야 풀린다.
- **Game 뷰 크기는 `GameViewSizes.currentGroupType` 묶음에 넣어야 한다.** 빌드 대상이 Android 인데 Standalone 묶음에
  넣으면 고른 뒤에도 엉뚱한 크기가 된다. 이번에 Standalone 묶음에 넣은 항목 하나가 남아 있다.
