# 화면 맞춤 · 세이브 판 올리기 작업 피드백 (2026-10-03)

게임 저장소에서 Unity CLI(`unity command …`)로 화면 비율 넷을 돌려 보고
세이브 판 올리기를 시험하며 본 것이다. Unity CLI 를 맡은 툴이 따로 없어 여기 적는다.

## 결론

- **화면 비율 시험은 CLI 만으로 끝까지 된다.** `PlayModeWindow.SetCustomRenderingResolution` 으로 Game 뷰 크기를 바꾸고
  `capture_game_view --source screen` 으로 찍으면 네 비율 × 여덟 화면을 사람 손 없이 볼 수 있었다.
- **끌기 시험은 `simulate_pointer` 로 안 된다.** 한 프레임짜리 누름이라 탭으로만 잡힌다.
  `InputSystem.QueueStateEvent` 로 마우스 상태를 한 장씩 넣어야 끌기가 된다.
- **Game 뷰 크기는 되돌리지 못했다.** 시험이 끝난 뒤 에디터에 맞춤 크기 넷이 남는다.

## 잘 된 것

- `eval` 에서 reflection 으로 private 메서드(`LoadFile`)를 임시 경로에 대고 불러, 세이브 파일 여덟 경우를
  사용자 세이브를 건드리지 않고 한 번에 돌렸다. 저장·불러오기처럼 파일을 만지는 코드 시험에 잘 맞는다.
- `eval` 로 `PrefabUtility.LoadPrefabContents` → 값 고침 → `SaveAsPrefabAsset` 이 한 번에 됐다 (앵커 값 하나 고치기).
- 코딩컨벤션의 「상수는 한 자리」 덕에 배율 계산을 정적 클래스 하나로 모으니 캔버스·카메라·끌기 문턱 세 군데가 한 줄씩만 바뀌었다.
- `console_status` 로 Play 중 오류 0 을 바로 확인했다.
