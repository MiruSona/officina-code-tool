# 타일 작업 컨벤션 피드백 (2026-09-20)

게임 저장소에서 타일 바닥·울타리를 까는 코드(인터페이스 1 · 구현 1 · enum 1 · 기존 파일 셋 고침)를
쓰면서 컨벤션 문서를 본 기록이다.

## 결론

- **컨벤션 문서가 짧아 바로 쓸 수 있었다.** 읽는 데 오래 안 걸리고 규칙이 번호로 붙어 있어 인용도 쉽다.
- **부딪힌 규칙이 하나 있다** — 「단일 사용 함수 금지」와 「깊이 3단계」가 이중 루프 안에서 같이 못 지켜진다.

## 잘 된 것

| 무엇 | 왜 좋았나 |
| --- | --- |
| 문서가 짧다 | 한 번 읽고 바로 코드를 썼다. 긴 규칙집은 작업 중에 다시 안 본다 |
| 규칙에 번호가 있다 | 설계 문서에서 「컨벤션 2-2 · 2-5 · 2-6」처럼 가리킬 수 있었다 |
| 내부 클래스 금지 · `?:`·`??` 금지 | 판단이 필요 없는 규칙이라 지키기 쉽고 diff 가 고르다 |
