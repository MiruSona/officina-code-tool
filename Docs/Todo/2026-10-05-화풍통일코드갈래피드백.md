# 화풍 통일 코드 갈래 피드백 (2026-10-05)

게임 저장소(ProjectMozzi2)에서 합성소 받기 연출 · 서랍 그림자 · 가판대 세움판 빼기를 하며 쓴 기록이다.

## 잘 된 것

- `UnityCLI함정.md` 의 「eval 은 Play 가 꺼져 있어도 성공한다」 덕에 상태 만들기 스크립트 첫 줄에 `Application.isPlaying` 확인을 넣었다.
- `eval_file` 로 Setup 둘(`SynthesisScreenSetup.Apply` · `StallScreenSetup.Apply`)을 한 번에 불러 프리팹을 다시 지었다. 막힘 없음.

## 헷갈린 것 · 함정 문서에 더하면 좋을 것

| 무엇 | 본 것 | 바라는 것 |
| --- | --- | --- |
| `InGameHub` 가 eval 에서 비어 보인다 (함정 6절) | 이번 판(Unity 6000.3.23f1 · CLI 1.0.0-beta.12)에서는 Play 중 `Mozzi.Game.InGameHub.Get<…>()` 가 **잘 됐다** | 6절에 「풀이름으로 부르면 된다 · 다시 확인한 판」을 적는다 |
| 연출 중간 장면 찍기 | `capture_game_view` 한 번이 1초쯤 걸려 0.9초짜리 연출은 `sleep` 으로 못 잡는다 (두 장이 같은 그림으로 나왔다) | 「eval 로 `GameMaster.TimeScale` · `Time.timeScale` 을 0.02 로 낮추고 찍은 뒤 되돌린다」 를 함정 문서에 적는다 |
| `console` 의 `counts.error` | 앞 세션의 「없는 명령」 오류 한 줄이 남아 컴파일 에러처럼 보였다 | 「컴파일 뒤에는 `clear_console` 먼저, 판정은 `groundTruth.consoleErrors` 로」 한 줄 |
| `unity command <이름> --help` | 명령별 인자가 아니라 공통 도움말만 나온다 | 「인자는 `unity command --query <이름>` 의 매개변수 열로 본다」 한 줄 |

## 3판 (고를 것 셋 캡처) 에서 본 것

- Play 중에 `Resources/Art/` 의 PNG 를 바꾸고 `AssetDatabase.Refresh()` 를 부르면 화면 그림이 그 자리에서 바뀐다 (C# 을 안 건드리면 도메인이 안 다시 읽힌다). `TimeScale 0` 으로 멈춰 두면 **같은 순간**을 그림만 바꿔 가며 찍을 수 있어 견줌판이 깨끗하다.
- `recompile_status` 는 고친 것이 없으면 `completed` 가 아니라 `up_to_date` 를 준다. 기다리는 루프가 `completed` 만 보면 끝까지 돈다.
