# 화풍 통일 코드 갈래 피드백 (2026-10-05)

게임 저장소(ProjectMozzi2)에서 합성소 받기 연출 · 서랍 그림자 · 가판대 세움판 빼기를 하며 쓴 기록이다.

## 잘 된 것

- `UnityCLI함정.md` 의 「eval 은 Play 가 꺼져 있어도 성공한다」 덕에 상태 만들기 스크립트 첫 줄에 `Application.isPlaying` 확인을 넣었다.
- `eval_file` 로 Setup 둘(`SynthesisScreenSetup.Apply` · `StallScreenSetup.Apply`)을 한 번에 불러 프리팹을 다시 지었다. 막힘 없음.

## 3판 (고를 것 셋 캡처) 에서 본 것

- Play 중에 `Resources/Art/` 의 PNG 를 바꾸고 `AssetDatabase.Refresh()` 를 부르면 화면 그림이 그 자리에서 바뀐다 (C# 을 안 건드리면 도메인이 안 다시 읽힌다). `TimeScale 0` 으로 멈춰 두면 **같은 순간**을 그림만 바꿔 가며 찍을 수 있어 견줌판이 깨끗하다.
- `recompile_status` 는 고친 것이 없으면 `completed` 가 아니라 `up_to_date` 를 준다. 기다리는 루프가 `completed` 만 보면 끝까지 돈다.

## 반복 06 (같은 날 · 갈래 넷 병렬 + Play 확인 한 판) 에서 본 것

| 무엇 | 본 것 | 바라는 것 |
| --- | --- | --- |
| `unity command eval --code "…"` | PowerShell 에서 C# 의 큰따옴표 · 세미콜론이 깨져 한 번도 못 썼다. 전부 파일로 써서 `eval_file --file` 로 돌렸다 | 함정 문서에 「PowerShell 에서는 `eval --code` 를 쓰지 말고 `eval_file` 만 쓴다」 한 줄 |
| `editor_pause` 중 `capture_game_view` | 멈춘 동안에는 Game 뷰가 다시 안 그려져 **옛 프레임**이 찍힌다. 연출 중간 장면은 멈춤 대신 게임 쪽 시간(디스패처 · `TimeScale 0`)을 멈추고 손으로 0.05초씩 돌려 찍었다 | 함정 문서에 「연출 캡처는 `editor_pause` 로 하지 않는다 — 게임 시간을 멈추고 손으로 돌린다」 를 적는다 |
| 에디터 하나를 여러 갈래가 같이 못 쓴다 | 코드 갈래 넷이 병렬로 돌았지만 Unity 에디터는 하나라, 컴파일 · Play 확인을 갈래마다 못 하고 **마지막 한 판으로 몰았다**. 갈래 안에서는 「코드는 맞는데 안 돌려 봤다」 로 끝난다 | 구조 안내에 「병렬 갈래는 EditMode 시험까지만, Play 확인은 합친 뒤 한 판」 을 적는다. 갈래별 확인이 꼭 필요하면 worktree + 에디터 둘을 쓰는 길을 조사할 값이 있다 |
