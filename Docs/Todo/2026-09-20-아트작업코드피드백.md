## Unity 구조 가이드에 넣을 만한 실측 두 개

애니를 코드 시계로 몰면서 얻은 것이다. `Docs/Research/2026-08-20-Unity프로젝트구조조사.md` 나 `csharp-unity.md` 에 패턴으로 넣을 만하다.

| 무엇 | 자세히 |
| --- | --- |
| Animator 를 코드 시계로 몰 때 | `speed = 0` 으로 세우고 `Play(hash, 0, t)` 로 진행률을 준 다음 **`Update(0f)` 를 꼭 불러야** 그 프레임이 실제로 반영된다. 안 부르면 값이 한 프레임 늦거나 아예 안 바뀐다 |
| 클립 한 벌을 여러 종이 나눠 쓰는 법 | 클립이 스프라이트를 직접 물지 않고 `[SerializeField] private int` 를 **FloatCurve 로 움직이게** 하면, 그 번호를 받아 자기 스프라이트를 고르는 스크립트만 종마다 다르면 된다. 찹쌀이 변종이 늘어도 클립은 한 벌이다 |
