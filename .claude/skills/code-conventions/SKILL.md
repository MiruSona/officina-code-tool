**원문은 코딩컨벤션 문서다.** 이 스킬은 체크리스트다. 원문이 없는 저장소면 아래 목록만 따른다.

| 어디서 쓰나 | 원문 경로 |
| --- | --- |
| 스튜디오(서브모듈로 물린 상태) | `CodeTool/Docs/Guide/코딩컨벤션.md` |
| CodeTool 저장소 단독 | `Docs/Guide/코딩컨벤션.md` |

로컬 LLM 에게 줄 짧은 요약본은 같은 폴더의 `코딩컨벤션-요약.md` 다.

## 코드 쓰기 전 체크리스트

- [ ] partial 은 되도록 안 쓴다
- [ ] 내부(중첩) 클래스 금지 — 파일을 나눈다
- [ ] 똑똑한 한 줄보다 평범한 세 줄 (3년차가 바로 읽힌다)
- [ ] 들여쓰기 3단계까지. 넘으면 함수로 뺄 때가 아니라 **일찍 빠져나올 때**다
- [ ] ?: 와 ?? 는 되도록 안 쓴다. ?. 도 조심
- [ ] 주석에 히스토리(누가·언제·왜 고쳤나) 금지. git 이 기억한다. 최대 2줄
- [ ] if 안이 2줄 이상이면 중괄호
- [ ] 2중첩부터는 한 줄이어도 중괄호
- [ ] 두 번 이상 반복되는 코드가 아니면 함수로 안 뺀다

**들여쓰기(4번)와 함수 빼기(9번)가 부딪히면 9번이 이긴다.** 일찍 빠져나오기로 푼다.

## 늘 걸리는 것

1. **한국어 주석·메시지, 코드 이름은 영어.** 코드를 보면 아는 것은 주석으로 안 쓴다.
2. **SOLID 는 순수 C# 에 전부, MonoBehaviour 는 컴포넌트 조합이 기본**이다.
3. **TDD — 규칙·셈법을 바꾸면 시험을 먼저 쓴다.**
4. **회귀 시험을 지우지 않는다.** 내 변경으로 깨지면 **그 시험이 재던 의도를 유지한 채**
   고치고, 의도를 바꿔야 하면 보고에 적는다.
5. **라이브러리·패키지를 마음대로 더하지 않는다.** 필요하면 더하지 말고 보고에 적는다 (AGENTS 7).
6. 임시 파일은 저장소 안이 아니라 **스크래치패드**에 만든다.
7. **PATH 같은 환경 변수는 에이전트가 못 바꾼다** — 필요하면 사용자에게 명령을 적어 준다.

파일을 쓰는 툴이면 `security-invariants` 도 본다.
