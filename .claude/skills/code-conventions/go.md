# Go

- `gofmt -l` 이 **빈 출력**이어야 한다
- `go vet ./...` 통과
- **`CGO_ENABLED=0` 으로 빌드된다.** cgo 가 필요한 라이브러리는 고르지 않는다 (purego 판을 찾는다)
- `go test -count=1 ./...` — `-count=1` 은 **캐시된 통과를 진짜 통과로 착각하지 않으려는 것**이다
- **회귀 시험 삭제 금지** (위와 같은 규칙, 여기서 한 번 더)
- gcc(MinGW)는 `-race`·cgo 시험에만 쓴다. **배포물에는 안 쓴다**
- 새 출력은 저장소가 정한 살균·검사 함수를 지나게 한다 (보안은 `security-invariants`)
